## Lab 5 Reflection Questions

When choose List over Set?
You would choose a List over a set if you wanted to have duplicate values.

Why HashSet before inserting a book ID?
Using a HashSet allows for only unique values which is important for storing IDs

Why a Map for “currently borrowed” vs only a boolean?
This creates a direct mapping for the book itself rather that a specific object with a boolean variable attached

HashMap vs TreeMap in this lab?
HashMap does not have values sorted like TreeMap does.

Comparable vs Comparator for books?
Comparable

Which iteration style would you use most in production—and why?
I would use a for loop in production as it offers the most control

CRM: which collection for customer list / unique emails / id→customer lookup?
Customer list -> ArrayList
Unique emails -> HashSet
id->customer lookup -> Hashmap
